Check a website

Type a website address to see the result of our automatic check of its home page. We show a site's result only when someone looks for it; we do not publish a list or a ranking.

For example example.com.tr

Good to know

  • Only the home page was checked, on 11 November 2026.
  • Automatic checks find only some problems. If no problems are found, the site may still be hard to use for some people.
  • This is not a legal audit.
  • Website owners can ask to be left out.
