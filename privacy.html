Privacy and legal notice

In short

  • This website does not use cookies, does not store anything in your browser and does not track you.
  • It has no forms, no accounts, no ads and no analytics, and it loads nothing from other companies' servers (no outside fonts, scripts or images).
  • It is hosted on GitHub Pages. GitHub, not us, receives the technical data that every website host receives, such as your IP address.

Who runs this website

The Türkiye Web Accessibility Report is a non-commercial project run by Yunus Kangal. It sells nothing and has no customers. Questions and requests go through the project's GitHub issues. Issues are public, so please do not write personal data in them.

Visiting this website

The site is a set of static files served by GitHub Pages. According to GitHub's documentation, when a GitHub Pages site is visited, the visitor's IP address is logged and stored by GitHub for security purposes (GitHub Pages documentation, GitHub General Privacy Statement). We do not receive these logs and we do not use any analytics.

The site is always served over HTTPS (encrypted connection).

Cookies

The site sets no cookies and uses no browser storage. That is why there is no cookie banner.

Checking a website

When you type an address on the "Check a website" page, it stays in your browser. The page turns the address into a code (a SHA-256 hash) and loads the result file with that code from GitHub Pages. GitHub can see which file was requested, but the page does not send the typed address anywhere.

Data about the checked websites

We store only technical results about the home pages we checked (which automatic rules failed and how often). We do not store page text, screenshots, cookies or personal data. Websites whose address is a person's own name were removed from all published data. How we collect and use these results is explained on How we did it.

Removing a website or asking about data

Website owners can ask to be left out with the opt-out form. We remove the site from all published data at the next publication. For any other question about data, open a GitHub issue.

Use of the results

  • The results come from an automatic check and are provided as they are, without any guarantee. They are not a legal audit, a certification or legal advice.
